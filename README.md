# 🚀 archline

**Arch Linux + Hyprland одной командой.** Запускаешь `install.sh` с
live-ISO — получаешь полностью настроенный рабочий стол: панель, темы,
обои, хоткеи, шелл, снапшоты.

Это не дистрибутив, а рецепт поверх официального Arch ISO. Ничего не
зашито под конкретную машину: имя, hostname и часовой пояс спрашиваются,
графика подбирается по железу.

---

## 📦 Установка

Нужна загрузочная флешка с **официальным Arch ISO** (Ventoy подойдёт).

⚠️ **Выключи Secure Boot** в BIOS — иначе установщик остановится.
⚠️ **Выбранный диск стирается полностью** — вместе с Windows.

### Вариант 1 — одна команда (проще всего)

В Arch ISO есть `git` и `curl`. Интернет нужен только на время
установки (ethernet поднимется сам, Wi-Fi — `iwctl station wlan0 connect "SSID"`):

```sh
bash <(curl -fsSL https://raw.githubusercontent.com/koloideal/archline/main/install.sh)
```

Скрипт сам клонирует репозиторий в `/tmp` и перезапускается из него.

### Вариант 2 — репозиторий на флешке Ventoy

Заранее кинь репозиторий на раздел с ISO-образами, а в live-среде:

```sh
mkdir -p /usb && mount -L Ventoy /usb && bash /usb/archline/install.sh
```

Метка `Ventoy` стоит по умолчанию; если другая — `lsblk` покажет
разделы, монтируй по имени: `mount /dev/sdX1 /usb`.
Не находит метку сразу после загрузки — `udevadm trigger; udevadm settle`.

### Что спросит скрипт

- 📶 Wi-Fi — если сети нет
- 👤 имя пользователя и hostname
- 🌍 часовой пояс (угадывает по IP, можно поправить)
- 💽 диск — если их несколько + подтверждение `YES`
- 🔒 пароль дважды (он же для root)

Дальше всё само: разметка → pacstrap → графика по железу →
конфиги → AUR → ребут в готовый стол.

### ⚡ Без вопросов — переменные

```sh
RA_USERNAME=ivan RA_HOSTNAME=thinkpad RA_TZ=Europe/Moscow \
  bash /usb/archline/install.sh
```

## 🖥️ Что получаешь

- **🌊 Hyprland** — готовые хоткеи, справка по `Super+H`
- **📊 Waybar + swaync + wofi + kitty + SwayOSD** — бар, уведомления,
  лаунчер и экранные индикаторы из коробки
- **🎨 Адаптивная тема** — бар и меню перекрашиваются под обои
  (тёмные → кремовые островки, светлые → тёмные)
- **🖼️ Пикер обоев `Super+W`** — сетка превью, поиск по имени,
  сортировка по частоте выбора; свои картинки — в `~/Pictures/wallpapers`
- **🔑 Автологин** — прямо в рабочий стол; пароль только для sudo
  и после блокировки (`Super+L`)
- **📸 Btrfs + snapper** — снапшот при установке пакетов,
  откат сломанного обновления одной командой
- **🛡️ earlyoom, ufw, zram, fstrim** — не повиснет от OOM,
  входящие закрыты, SSD обслуживается сам

## 📸 Хочешь свою систему, а не мою

`install.sh` ставит **бандл** — `dotfiles/home.tar.gz`, архив домашних
конфигов. В репозитории лежит мой, но ты можешь собрать свой:

```sh
./collect.sh    # → dotfiles/home.tar.gz
```

Запускай на своём настроенном Arch — скрипт копирует конфиги из `$HOME`
(Hyprland, шелл, темы, приложения) и выкидывает машинный мусор: state-файлы,
закладки, координаты (список исключений `LEGACY` внутри скрипта).
Поверх накладывается `overlay/home/` — файлы, написанные руками в репе:
`hyprland.lua`, скрипты, стартовые обои.

При установке бандл привязывается к новой машине автоматически:
все `/home/<старое>` переписываются на нового пользователя, графика
подбирается по железу, идентичность спрашивается. Бандл, собранный
на одном ноуте, встаёт на любой другой без ручной чистки.

Если конфиги устраивают, а софт хочется другой — правь списки
`packages/pacman.txt` и `packages/aur.txt` (по имени пакета на строку).

## 📴 Оффлайн-установка

Если ставить там, где нет интернета — собери локальный пул пакетов
на своей системе (не на live-ISO):

```sh
./sync-repo.sh    # → repo/ + extras/ (~2-3 ГБ)
```

Скрипт выкачивает `pacman.txt` с полным замыканием зависимостей,
собирает `aur.txt` через `makepkg` и индексирует локальное репо
(нужны `pacman-contrib`, `base-devel`, `git`).

`install.sh` сам увидит `repo/` рядом: без сети — ставит из пула
(предложит задать Wi-Fi для новой системы), с сетью — спросит:
пул или интернет. `RA_REPO=local|online` — выбор без вопроса.
Пул — снапшот версий на день сборки, обновляется перезапуском.

⚠️ Оффлайн — только вариант с флешкой: репу и `repo/` нужно заранее
положить на неё с другого компьютера.

## ⚠️ Ограничения

- **UEFI only** — legacy BIOS не поддерживается
- **диск целиком** — дуалбут и ручная разметка не предусмотрены
- **x86_64** — ARM не соберётся
- **фиксированный стек**: `linux-zen`, Btrfs (`@ @home @pkg @log`),
  systemd-boot + UKI, zram; без LUKS, без GRUB
- **iGPU-pin только на Intel** — на AMD+NVIDIA GPU выберет сам Aquamarine
