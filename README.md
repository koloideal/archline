# archline

**Автоматизированная установка Arch Linux + Hyprland.** `install.sh`
запускается из live-ISO и разворачивает преднастроенный рабочий стол:
панель, темы, обои, горячие клавиши, shell и снимки состояния.

Проект не является дистрибутивом: это сценарий установки поверх
официального Arch ISO. Параметры, зависящие от машины, не зашиты в код:
имя пользователя, hostname и часовой пояс запрашиваются при установке,
графический стек определяется по оборудованию.

## Установка

Требуется загрузочная флешка с **официальным Arch ISO** (поддерживается
в том числе Ventoy).

**Важно:** Secure Boot необходимо отключить в BIOS. При включённом
Secure Boot установщик завершает работу.

**Важно:** выбранный диск очищается полностью, включая существующие
разделы и данные Windows.

### Вариант 1: одна команда

В Arch ISO уже есть `git` и `curl`. Сеть требуется только на время
установки: Ethernet настраивается автоматически, для Wi-Fi используйте
`iwctl station wlan0 connect "SSID"`.

```sh
bash <(curl -fsSL https://raw.githubusercontent.com/koloideal/archline/main/install.sh)
```

Скрипт клонирует репозиторий в `/tmp` и перезапускается из локальной копии.

### Вариант 2: репозиторий на флешке Ventoy

Скопируйте репозиторий на раздел с ISO-образами, затем в live-среде выполните:

```sh
mkdir -p /usb && mount -L Ventoy /usb && bash /usb/archline/install.sh
```

Метка `Ventoy` используется по умолчанию. Если метка другая, список
разделов можно получить через `lsblk` и смонтировать нужный раздел вручную:
`mount /dev/sdX1 /usb`. Если устройство не появилось сразу после загрузки,
выполните `udevadm trigger; udevadm settle`.

### Параметры, запрашиваемые установщиком

- Wi-Fi, если сетевое подключение отсутствует
- имя пользователя и hostname
- часовой пояс (предлагается значение по IP, можно указать другое)
- диск для установки, если доступно несколько дисков, и подтверждение `YES`
- пароль пользователя (тот же пароль используется для root)

Далее выполняются разметка, `pacstrap`, настройка графического стека,
развёртывание конфигурации, установка AUR-пакетов и перезагрузка в
настроенную систему.

### Установка без интерактивных вопросов

```sh
RA_USERNAME=ivan RA_HOSTNAME=thinkpad RA_TZ=Europe/Moscow \
  bash /usb/archline/install.sh
```

## Состав системы

- **Hyprland** — настроенные горячие клавиши, справка по `Super+H`
- **Waybar + swaync + wofi + kitty + SwayOSD** — панель, уведомления,
  launcher и экранные индикаторы
- **Адаптивная тема** — цвета панели и меню вычисляются по текущим обоям:
  для тёмных обоев используются светлые элементы, для светлых — тёмные
- **Выбор обоев по `Super+W`** — сетка превью, поиск по имени и сортировка
  по частоте выбора; пользовательские изображения размещаются в
  `~/Pictures/wallpapers`
- **Автоматический вход** — вход выполняется без greeter; пароль требуется
  для sudo и после блокировки экрана (`Super+L`)
- **Btrfs + snapper** — снимки состояния при установке пакетов и откат неудачного
  обновления одной командой
- **earlyoom, ufw, zram, fstrim** — контроль нехватки памяти до зависания системы,
  закрытые входящие соединения, сжатый swap в оперативной памяти
  и периодический TRIM для SSD

## Использование собственной конфигурации

`install.sh` устанавливает бандл `dotfiles/home.tar.gz` — архив домашних
конфигурационных файлов. В репозитории находится готовый бандл, но его
можно пересобрать на другой системе:

```sh
./collect.sh    # создаёт dotfiles/home.tar.gz
```

Запуск выполняется на уже настроенной системе Arch. Скрипт копирует
конфигурации из `$HOME` (Hyprland, shell, темы, приложения) и исключает
машинно-зависимые файлы: файлы состояния, закладки и координаты. Список
исключений определён в `LEGACY` внутри скрипта. Поверх собранных файлов
накладывается `overlay/home/` — поддерживаемые вручную файлы репозитория:
`hyprland.lua`, скрипты и стартовые обои.

Во время установки бандл адаптируется к новой машине автоматически:
пути `/home/<старое имя>` заменяются на `/home/<новый пользователь>`, графический
стек выбирается по оборудованию, пользовательские параметры запрашиваются
установщиком. Бандл, собранный на одной машине, может быть развёрнут на
другой без ручной очистки путей.

Для изменения набора программ отредактируйте `packages/pacman.txt` и
`packages/aur.txt` — по одному имени пакета на строку.

## Оффлайн-установка

Для установки без доступа к интернету необходимо заранее собрать локальный
репозиторий пакетов на рабочей системе (не на live-ISO):

```sh
./sync-repo.sh    # создаёт repo/ и extras/ (~2–3 ГБ)
```

Скрипт загружает `pacman.txt` с полным замыканием зависимостей, собирает
`aur.txt` через `makepkg` и создаёт индекс локального репозитория.
Требуются `pacman-contrib`, `base-devel` и `git`.

Если рядом с `install.sh` есть каталог `repo/`, установщик использует его
как источник пакетов. Без сети локальный репозиторий выбирается автоматически;
при доступной сети установщик предлагает выбрать локальный репозиторий или зеркала.
Для неинтерактивного выбора используется `RA_REPO=local|online`. Локальный репозиторий
фиксирует версии пакетов на дату сборки и обновляется повторным запуском
`sync-repo.sh`.

**Важно:** оффлайн-установка поддерживается только с флешки. Репозиторий
и каталог `repo/` необходимо заранее скопировать на неё с другой машины.

## Ограничения

- **UEFI only** — legacy BIOS не поддерживается
- **диск используется целиком** — dual boot и ручная разметка не предусмотрены
- **x86_64** — ARM не поддерживается
- **фиксированный стек**: `linux-zen`, Btrfs (`@ @home @pkg @log`),
  systemd-boot + UKI, zram; без LUKS и GRUB
- **iGPU-pin только на Intel** — на AMD+NVIDIA GPU выбирается средствами
  Aquamarine
