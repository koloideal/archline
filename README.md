# Relocatable Arch

Переносимая рабочая система: **Arch Linux + Hyprland**, которая ставится
на любую машину из одного git-репозитория. Это не дистрибутив —
это *рецепт*: установочный скрипт, списки пакетов и полный набор
конфигов, собранный так, чтобы после одной команды с live-ISO
получался готовый повседневный десктоп для человека, который в Linux
новичок.

## Идея

Обычно «свой Arch» живёт только в одном месте: убьёшь систему —
начинай с нуля. Здесь конфигурация оторвана от конкретной машины:
в бандле нет имён пользователей, абсолютных домашних путей,
координат города или привязки к названию дисплея. Имя пользователя,
hostname и часовой пояс спрашиваются при установке — можно поставить
себе, другу, на второй ноут, в виртуалку.

## Что ставится

| Слой | Что внутри |
|---|---|
| База | ядро `linux-zen`, systemd-boot с UKI, Btrfs (`@`, `@home`, `@pkg`, `@log`), zram |
| Графика | Hyprland (Lua-конфиг, >= 0.55), greetd с автологином, uwsm |
| Окружение | Waybar «островами», swaync, wofi, kitty, SwayOSD, awww |
| Звук | PipeWire + WirePlumber, pavucontrol |
| Защита новичка | snapper-автоснапшоты на каждый `pacman`, earlyoom, ufw, fstrim |
| Удобство | ночной свет (geoclue2), tap-to-click, справка по хоткеям `Super+H` |

Из пользовательского:

- **Waybar** — четыре «острова»: workspaces, система, профили, питание
- **Пикер обоев `Super+W`** — GTK4-сетка миниатюр, живое превью
  по стрелкам и мыши, fade-переход через `awww`
- **Справка `Super+H`** — плавающее окно с основными хоткеями,
  закрывается по `q` и по `й`
- **Стартовый звук** — играет один раз после появления реального
  аудио-sink, возвращает громкость на место
- **Блокировка `Super+L`** — единственное место, где спрашивается
  пароль; вход в сессию без greeter-окна

## Структура

```
├── install.sh          # установщик: разметка → pacstrap → конфиги (из live-ISO, от root)
├── collect.sh          # собирает конфиги текущей системы в dotfiles/home.tar.gz
├── overlay/home/       # руками написанные конфиги, накладываются поверх собранных
├── dotfiles/           # home.tar.gz — собранный бандл домашних конфигов
└── packages/
    ├── pacman.txt      # пакеты из официальных репозиториев
    ├── aur.txt         # пакеты из AUR (ставятся через yay)
    └── mirrorlist      # запасной список зеркал, если reflector недоступен
```

`collect.sh` и `install.sh` — зеркальные друг другу: первый снимает
живую систему в бандл, второй разворачивает бандл на чистый диск.

## Установка

Нужна любая загрузочная флешка с Arch Linux (например, Ventoy +
официальный ISO) и этот репозиторий на ней же.

```sh
udevadm trigger; udevadm settle
mkdir -p /usb && mount -L Ventoy /usb          # или метка твоей флешки
bash /usb/Relocatable_Arch/install.sh
```

Скрипт спросит: Wi-Fi (если нет сети), имя пользователя, hostname,
часовой пояс (по умолчанию определяется через geo-IP), диск —
и дважды пароль. **Выбранный диск стирается полностью.**

Параметры можно передать заранее, без вопросов:

```sh
RA_USERNAME=ivan RA_HOSTNAME=thinkpad RA_TZ=Europe/Moscow \
  bash /usb/Relocatable_Arch/install.sh
```

После перезагрузки — готовая сессия Hyprland: обои, звук, справка
по `Super+H`, всё на месте.

## Снятие бандла с живой системы

На настроенной машине:

```sh
./collect.sh    # → dotfiles/home.tar.gz
```

Система при этом не изменяется: скрипт только копирует файлы из
`PATHS` в `collect.sh`, выкидывает машинно-зависимый мусор
(закладки, state-файлы, старые конфиги из `LEGACY`) и накладывает
поверх `overlay/home/`.

## Проверка перед коммитом

```sh
bash -n install.sh collect.sh
Hyprland --verify-config -c overlay/home/.config/hypr/hyprland.lua
./collect.sh
```

## Основные хоткеи

| Комбинация | Действие |
|---|---|
| `Super+Enter` | kitty |
| `Super+D` | wofi, запуск приложений |
| `Super+E` | файловый менеджер |
| `Super+W` | пикер обоев |
| `Super+H` | справка по хоткеям (`q`/`й` — закрыть) |
| `Super+L` | блокировка |
| `Super+X` | меню питания |
| `Super+Q` | закрыть окно |
| `Super+Shift+Q` | выйти из сессии |
| `Super` + `1..0` | workspace |
| `Super+Shift` + `1..0` | перенести окно на workspace |
| `Print` / `Shift+Print` | скриншот экрана / области |

Полный список — внутри самой системы по `Super+H`.
