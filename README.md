# 🚀 myArch

**Arch Linux + Hyprland одной командой** — от чистого диска до полностью
готового рабочего стола за один запуск установщика.

Это не дистрибутив, а **рецепт**: обычный скрипт поверх официального
Arch ISO. Он размечает диск, ставит пакеты, разворачивает конфиги —
и перезагружает тебя прямо в настроенный Hyprland.

✨ Никакой привязки к железу и никаких чужих артефактов: имя
пользователя, hostname и часовой пояс спрашиваются при установке.

---

## 🖥️ Что получается на выходе

- **🌊 Hyprland** — готовые хоткеи и справка по `Super+H`,
  читать вики не нужно
- **📊 Waybar, swaync, wofi, kitty, SwayOSD** — панель, уведомления,
  запуск приложений и экранные индикаторы громкости/яркости из коробки
- **🎨 Адаптивная тема** — панель и меню сами перекрашиваются под
  выбранные обои (тёмные → кремовые островки, светлые → тёмные)
- **🔑 Автологин** — система грузится сразу в рабочий стол, пароль
  нужен только для sudo и после блокировки (`Super+L`)
- **📸 Btrfs + snapper** — снапшот при каждой установке пакетов;
  сломанное обновление откатывается одной командой
- **🛡️ earlyoom, ufw, zram, fstrim** — не повиснет от OOM,
  входящие закрыты, SSD обслуживается сам
- **🖼️ Пикер обоев по `Super+W`** — сетка превью, живое перекрашивание,
  поиск по имени и сортировка «часто выбираемое вперёд»; свои картинки
  просто кидаются в `~/Pictures/wallpapers`

## 📦 Установка

Нужна флешка с **официальным Arch ISO** (Ventoy подойдёт) и этот
репозиторий на ней же.

⚠️ **Заранее:** выключи **Secure Boot** в BIOS — иначе установщик
остановится. И помни: **выбранный диск стирается полностью** —
вместе с Windows, если она там была.

```sh
udevadm trigger; udevadm settle
mkdir -p /usb && mount -L Ventoy /usb
bash /usb/myArch/install.sh
```

Скрипт спросит:

- 📶 Wi-Fi — если сети нет
- 👤 имя пользователя и hostname
- 🌍 часовой пояс (сам угадывает по IP, можно поправить)
- 💽 диск — если их несколько, и подтверждение `YES`
- 🔒 пароль дважды (он же для root)

Дальше всё само: разметка → pacstrap → NVIDIA/AMD по железу →
конфиги → AUR → перезагрузка в готовый стол.

### ⚡ Без вопросов — через переменные

```sh
RA_USERNAME=ivan RA_HOSTNAME=thinkpad RA_TZ=Europe/Moscow \
  bash /usb/myArch/install.sh
```

## 📸 Свой бандл: как это работает

**Важно понять одну вещь:** установщик ставит не «конфиги из репозитория»,
а **бандл** — `dotfiles/home.tar.gz`. Это архив чьих-то домашних
конфигов (Hyprland, шелл, темы, приложения). В репозитории его нет —
он в `.gitignore` и генерируется каждым под себя.

Откуда бандл берётся:

- **у меня** — собран с моей системы через `collect.sh`, и уже на флешке;
- **у тебя** — либо ставь как есть, либо собери свой.

Есть три пути:

**1. Ставить чей-то готовый бандл.** Если тебе передали
`home.tar.gz` — положи его в `dotfiles/` и запускай `install.sh`.
Всё встанет как у автора бандла.

**2. Собрать бандл со своей текущей системы.** Если у тебя уже стоит
Arch и ты его настроил — склонируй репозиторий и выполни:

```sh
./collect.sh    # → dotfiles/home.tar.gz
```

Скрипт копирует твои конфиги из `$HOME` в архив: Hyprland, kitty, wofi,
swaync, темы GTK/Qt, шелл (`.zshrc` и компания), конфиги приложений.
При этом он **выкидывает машинный мусор**: state-файлы, закладки,
координаты, устаревшие конфиги — список исключений в `LEGACY` внутри
скрипта, пополняется по мере находок.

Поверх собранного накладывается `overlay/home/` — файлы, которые в
репозитории написаны руками: `hyprland.lua`, скрипты пикера обоев,
справка по хоткеям. То есть бандл = твои конфиги + ручные правки
поверх них.

**3. Просто поправить списки пакетов.** Если конфиги устраивают,
а хочется другой набор софта — отредактируй `packages/pacman.txt`
и `packages/aur.txt` (по имени пакета на строку) и ставь.

### Почему бандл переносится на любую машину

При установке `install.sh` делает три вещи, которые решают
«привязку» к чужой системе:

- **переписывает пути** — все `/home/<старое имя>` внутри конфигов
  заменяются на `/home/<новый пользователь>`;
- **подбирает графику под железо** — NVIDIA-блок ставится только при
  наличии NVIDIA, на AMD добавляются `vulkan-radeon`/`libva-mesa-driver`;
- **спрашивает идентичность** — имя, hostname и таймзону никто не
  зашивает в бандл.

Итог: бандл, собранный на одном ноуте, встаёт на любой другой —
без ручной чистки конфигов.

## ⚠️ Ограничения

Установщик делает осознанные допущения — проверь, что тебе подходит:

- **UEFI only** — legacy BIOS не поддерживается, Secure Boot выключить
- **диск целиком** — одна система на диск, дуалбут и ручная разметка
  не предусмотрены
- **x86_64** — ARM и прочие архитектуры не соберутся
- **нужен интернет** — пакеты качаются из репозиториев Arch и AUR;
  из коробки поднимается только Wi-Fi (ethernet работает, если уже есть сеть)
- **фиксированный стек**: `linux-zen`, Btrfs (`@ @home @pkg @log`),
  systemd-boot + UKI, zram. Без LUKS, без GRUB
- **iGPU-pin гарантирован только на Intel** — udev-правило знает Intel;
  на AMD+NVIDIA Aquamarine выбирает GPU сама (обычно верно)
