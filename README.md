# 🚀 myArch

**Arch Linux + Hyprland одной командой** — от чистого диска до полностью
готового рабочего стола за один запуск установщика.

Это не дистрибутив, а **рецепт**: обычный скрипт поверх официального
Arch ISO. Он размечает диск, ставит пакеты, разворачивает конфиги —
и перезагружает тебя прямо в настроенный Hyprland.

✨ Никакой привязки к железу и никаких чужих артефактов: имя
пользователя, hostname и часовой пояс спрашиваются при установке.

---

## 🖥️ Что получается на выходе

- **🌊 Hyprland** — готовые хоткеи и справка по `Super+H`,
  читать вики не нужно
- **📊 Waybar, swaync, wofi, kitty, SwayOSD** — панель, уведомления,
  запуск приложений и экранные индикаторы громкости/яркости из коробки
- **🎨 Адаптивная тема** — панель и меню сами перекрашиваются под
  выбранные обои (тёмные → кремовые островки, светлые → тёмные)
- **🔑 Автологин** — система грузится сразу в рабочий стол, пароль
  нужен только для sudo и после блокировки (`Super+L`)
- **📸 Btrfs + snapper** — снапшот при каждой установке пакетов;
  сломанное обновление откатывается одной командой
- **🛡️ earlyoom, ufw, zram, fstrim** — не повиснет от OOM,
  входящие закрыты, SSD обслуживается сам
- **🖼️ Пикер обоев по `Super+W`** — сетка превью, живое перекрашивание,
  поиск по имени и сортировка «часто выбираемое вперёд»; свои картинки
  просто кидаются в `~/Pictures/wallpapers`

## 📦 Установка

Нужна флешка с **официальным Arch ISO** (Ventoy подойдёт) и этот
репозиторий на ней же.

⚠️ **Заранее:** выключи **Secure Boot** в BIOS — иначе установщик
остановится. И помни: **выбранный диск стирается полностью** —
вместе с Windows, если она там была.

```sh
udevadm trigger; udevadm settle
mkdir -p /usb && mount -L Ventoy /usb
bash /usb/myArch/install.sh
```

Скрипт спросит:

- 📶 Wi-Fi — если сети нет
- 👤 имя пользователя и hostname
- 🌍 часовой пояс (сам угаждает по IP, можно поправить)
- 💽 диск — если их несколько, и подтверждение `YES`
- 🔒 пароль дважды (он же для root)

Дальше всё само: разметка → pacstrap → NVIDIA/AMD по железу →
конфиги → AUR → перезагрузка в готовый стол.

### ⚡ Без вопросов — через переменные

```sh
RA_USERNAME=ivan RA_HOSTNAME=thinkpad RA_TZ=Europe/Moscow \
  bash /usb/myArch/install.sh
```

## 📸 Собрать бандл из своей системы

Хочешь свой вариант? Настрой систему как нравится и выполни
в репозитории:

```sh
./collect.sh    # → dotfiles/home.tar.gz
```

Скрипт снимает конфиги из твоего `$HOME` в бандл, отрезая
машинно-зависимый мусор (закладки, state-файлы, старые бэкенды обоев).
При установке все `/home/<старое имя>` автоматически переписываются
на нового пользователя — **бандл с одной машины встаёт на любую**.

💡 Графика подбирается под железо: NVIDIA-блок ставится только при
наличии NVIDIA, на AMD добавляются `vulkan-radeon`/`libva-mesa-driver`.

## ⌨️ Основные хоткеи

| Комбинация | Действие |
|---|---|
| `Super+Enter` | терминал |
| `Super+D` | запуск приложений |
| `Super+E` | файловый менеджер |
| `Super+H` | справка (`Esc`/`q` — закрыть) |
| `Super+W` | пикер обоев |
| `Super+L` | блокировка экрана |
| `Super+X` | меню питания |
| `Super` + `1..0` | рабочие столы |
| `Print` / `Shift+Print` | скриншот экрана / области |

Полный список — по `Super+H` внутри системы.

## 🗂️ Структура репозитория

| Путь | Что это |
|---|---|
| `install.sh` | установщик: разметка → pacstrap → конфиги |
| `collect.sh` | снимок конфигов текущей системы в бандл |
| `overlay/home/` | конфиги, написанные вручную |
| `dotfiles/home.tar.gz` | собранный бандл (в `.gitignore`, у каждого свой) |
| `packages/` | списки пакетов (`pacman.txt`, `aur.txt`, `mirrorlist`) |
