# myArch

Arch Linux + Hyprland, который ставится на любую машину одной командой —
и сразу готов к повседневной работе. Скрипт размечает диск, ставит пакеты,
разворачивает конфиги и перезагружает в настроенный рабочий стол.

Не дистрибутив, а рецепт: обычный установщик поверх официального Arch ISO.
Никакой привязки к конкретному железу и никаких чужих артефактов —
имя пользователя, hostname и часовой пояс спрашиваются при установке.

## Что получается на выходе

- **Hyprland** с готовыми хоткеями и справкой по `Super+H` — не нужно
  читать вики, чтобы начать пользоваться
- **Waybar, swaync, wofi, kitty, SwayOSD** — панель, уведомления,
  запуск приложений и OSD громкости/яркости работают из коробки
- **Автологин** — система грузится сразу в рабочий стол, пароль
  нужен только для sudo и после блокировки (`Super+L`)
- **Btrfs + snapper** — автоматический снапшот системы при каждой
  установке пакетов; сломанное обновление откатывается одной командой
- **earlyoom, ufw, zram, fstrim** — ноутбук не повиснет от OOM,
  входящие соединения закрыты, SSD обслуживается сам
- **Обои и пикер по `Super+W`** — в бандле одна дефолтная обоина;
  свои картинки кидаются в `~/Pictures/wallpapers`, пикер покажет их
  сеткой с живым превью по стрелкам и мыши

## Установка

Нужна флешка с официальным Arch ISO (Ventoy подойдёт) и этот
репозиторий на ней же.

```sh
udevadm trigger; udevadm settle
mkdir -p /usb && mount -L Ventoy /usb
bash /usb/myArch/install.sh
```

Скрипт спросит: Wi-Fi (если нет сети), имя пользователя, hostname,
часовой пояс, диск и дважды пароль. **Выбранный диск стирается
полностью** — вместе с Windows, если она там была.

Без вопросов — через переменные:

```sh
RA_USERNAME=ivan RA_HOSTNAME=thinkpad RA_TZ=Europe/Moscow \
  bash /usb/myArch/install.sh
```

## Собрать свой бандл

Если хочется свой вариант конфигов — не обязательно править файлы
вручную. Настрой систему как нравится, затем в репозитории:

```sh
./collect.sh    # → dotfiles/home.tar.gz
```

Скрипт копирует конфиги из твоего `$HOME` в бандл, отрезая
машинно-зависимый мусор (закладки, state-файлы). При установке
все `/home/<старое имя>` автоматически переписываются на нового
пользователя — бандл с одной машины встаёт на любую другую.

## Структура

| Путь | Что это |
|---|---|
| `install.sh` | установщик: разметка → pacstrap → конфиги |
| `collect.sh` | снимок конфигов текущей системы в бандл |
| `overlay/home/` | конфиги, написанные вручную |
| `dotfiles/home.tar.gz` | собранный бандл домашних конфигов |
| `packages/` | списки пакетов (`pacman.txt`, `aur.txt`) |

## Основные хоткеи

| Комбинация | Действие |
|---|---|
| `Super+Enter` | терминал |
| `Super+D` | запуск приложений |
| `Super+E` | файловый менеджер |
| `Super+H` | справка (`q`/`й` — закрыть) |
| `Super+W` | обои |
| `Super+L` | блокировка |
| `Super+X` | меню питания |
| `Super` + `1..0` | рабочие столы |
| `Print` / `Shift+Print` | скриншот экрана / области |
